# ④ 乱数で毎回ちがう動きに

何が出るかは、お楽しみ

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

**乱数**を使うと、毎回ちがう数が出てくるよ。

- **ランダムな場所**に出す
- **ランダムな時間**だけ待つ
- **サイコロ**を作って、出る目を予想する

> ゲームが毎回ちがう動きになって、**何回あそんでも楽しく**なるよ。

:::

📷 ここに完成したようす：ネコがステージのいろいろな場所に出てくるようす

---

# 乱数ってなに？

:::

1. 「**演算**」の「**1 から 10 までの乱数**」をコードエリアに置く
2. ブロックを何回もクリック
3. クリックするたびに、**ちがう数**が出るね

> 1 から 10 のどれが出るかは、コンピューターにもわからない。サイコロをふるのと同じなんだ。

:::

📷 ここにブロックの画面：「1 から 10 までの乱数」をクリックして、数が出ているところ

---

# ランダムな場所に出す

:::

1. 「**x座標を 0 、y座標を 0 にする**」を置く
2. x の白い丸に「**乱数**」のブロックを入れ、**-200 から 200** にする
3. y の白い丸にも入れて、**-150 から 150** にする
4. ブロックをクリック

> 白い丸には、**まるい形**のブロックを入れられるよ。

:::

📷 ここにブロックの画面：「x座標を （-200 から 200 までの乱数）、y座標を （-150 から 150 までの乱数） にする」

---

# ランダムな待ち時間

:::

出たり隠れたりするネコを作ろう。

1. 緑の旗の下に「**ずっと**」
2. 中に「**隠す**」と「**（1 から 3 までの乱数） 秒待つ**」
3. 次に「ランダムな場所に出す」ブロックと「**表示する**」
4. 最後に「**1 秒待つ**」

> いつ出てくるかわからないから、ドキドキするね。もぐらたたきは、このしくみで作れるよ。

:::

📷 ここにブロックの画面：出たり隠れたりするスクリプト

---

# ランダムな色・大きさ・向き

:::

ほかのブロックの白い丸にも、乱数を入れられるよ。

- 「**色 の効果を （0 から 200 までの乱数） にする**」
- 「**大きさを （50 から 150 までの乱数） %にする**」
- 「**（1 から 360 までの乱数） 度に向ける**」

> 「出たり隠れたり」のスクリプトに入れると、出てくるたびに見た目が変わるよ。

:::

📷 ここにブロックの画面：3つのブロックの白い丸に、乱数が入っているところ

---

# サイコロを作ろう

:::

1. 変数「**サイコロ**」を作る
2. 緑の旗の下に「**サイコロ を （1 から 6 までの乱数） にする**」
3. その下に「**こんにちは! と 2 秒言う**」をつなぐ
4. 「こんにちは!」のところに「**サイコロ**」のブロックを入れる

緑の旗を押すたびに、ネコがサイコロの目を言うよ。

:::

📷 ここにブロックの画面：サイコロのスクリプトと、ネコが「4」と言っているステージ

---

# 「どこかの場所」とのちがい

:::

b1 の「**どこかの場所 へ行く**」も、行き先は毎回ちがったね。

- 「**どこかの場所 へ行く**」… ステージ**全体**のどこか
- 乱数で x と y を決める … **自分で決めた**はんいのどこか

> たとえば y を **-150 から 0** にすると、ステージの**下半分**にだけ出てくるよ。

:::

📷 ここにブロックの画面：「どこかの場所 へ行く」と、y を -150 から 0 にした乱数のブロック

---

# 🎮 ミニゲーム：サイコロ予想

:::

**🔮 予想** … 次に出る目を、先に予想しよう！

1. 出ると思う目（1〜6）を、となりの人に言う
2. 緑の旗をクリック
3. ネコが言った目と同じなら、**1点**
4. 10回やって、何点とれるかな？

> 2人で同じ目を予想してもいいよ。どっちが多く当てるか勝負しよう。

:::

📷 ここに画面：ネコがサイコロの目を言っているステージ

---

# やってみよう

:::

1. ランダムな場所に出たり隠れたりするネコを作る
2. ネコをクリックしたら、ランダムな場所にワープするようにする
3. 出てくるたびに、色や大きさを変える
4. ネコを下半分にだけ出す
5. サイコロを2つにして、合計を言わせる

> 合計は「**演算**」の「**〇 + 〇**」で作れるよ。

:::

📷 ここに動いているようす：出てくるたびに色と大きさが変わるネコ
