# ⑧ クイズゲーム

パターン：質問して答えをたしかめる

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

ネコが**問題**を出して、きみが**答え**を入れる。

- 答えは、キーボードで**入力**する
- 正解なら**得点**
- まちがいなら、正しい答えを教えてくれる

> このゲームのポイントは「**質問して答えをたしかめる**」だよ。

:::

📷 ここに画面：完成したクイズゲーム（ネコが問題を出して、ステージの下に入力らんが出ているところ）

---

# このゲームのしくみ

:::

**登場するもの**

- **ネコ** … 問題を出して、答えをたしかめる

**ルール**

1. ネコが問題を出して、答えを待つ
2. 入力された答えが正しいかを調べる
3. 正解なら得点が 1 ふえる。まちがいなら正しい答えを言う
4. 3問出したら、得点を言っておしまい

:::

📷 ここに画面：問題 → 答える → 正解・まちがい の流れを矢印でつないだ図

---

# 新しいブロック：「聞いて待つ」と「答え」

:::

水色の「**調べる**」に、質問のためのブロックがあるよ。

- 「**あなたの名前は何ですか? と聞いて待つ**」… ネコが質問して、ステージの下に**入力らん**が出る。答えが入るまで待つ
- 「**答え**」… 入力された答えが入っている、まるいブロック

> 入力したら、**エンターキー**か、入力らんの右のボタンを押してね。

:::

📷 ここにブロックの画面：「あなたの名前は何ですか? と聞いて待つ」と「答え」、ステージの下の入力らん

---

# 1問目を作ろう

:::

1. 緑の旗 →「**得点 を 0 にする**」
2. 「**3 + 4 は? と聞いて待つ**」
3. 「**もし 〜 なら / でなければ**」の穴に「**（答え） = 7**」
4. 上の口に「**せいかい! と 1 秒言う**」と、得点を 1 ふやす
5. 下の口に「**ざんねん、答えは 7 だよ と 2 秒言う**」

> ⚠ 数字は**半角**で入力してね。日本語入力のままだと「７」になって、まちがいになるよ。

:::

📷 ここにブロックの画面：1問目のスクリプト

---

# 問題をふやそう

:::

1. 「**3 + 4 は? と聞いて待つ**」を**右クリック**して「**複製**」
2. 下のブロックもいっしょにコピーされるので、1問目の下につなぐ
3. 問題と答えを、2問目に書きかえる
4. 同じようにして、3問目も作る
5. いちばん下に「**得点 と 2 秒言う**」

> 「こんにちは!」のところに「**得点**」のブロックを入れると、得点をしゃべるよ。

:::

📷 ここにブロックの画面：3問つながったスクリプト（全体）

---

# 🎮 あそんで勝負しよう

:::

**⚔ 勝負** … 自分のクイズを、となりの人に出そう！

1. 3問の問題を、自分で考えて作る（好きなものクイズでもOK）
2. となりの人に、自分のクイズをといてもらう
3. 自分も、となりの人のクイズをとく
4. 得点が多かった方の勝ち！

> むずかしすぎる問題は、だれも答えられないよ。答えがひとつに決まる問題にしよう。

:::

📷 ここに画面：ネコが「せいかい!」と言っているステージ

---

# 💪 改造してみよう

:::

1. 正解のときと、まちがいのときで、ちがう音を鳴らす
2. 問題を **5問** にふやす
3. 正解するたびに、ネコの**コスチューム**を変える
4. 全問正解したら「**すごい!**」と言う
5. 問題ごとに、**背景**を変える

> 答えが文字のときは、ひらがな・カタカナのどちらで入れるかを、問題の中で決めておこう。

:::
