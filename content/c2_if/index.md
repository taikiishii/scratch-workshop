# ② もしも〜なら

ふれたら・押したら、を見分けよう

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

「**もし 〜 なら**」で、そのときのようすに合わせて動きを変えよう。

- マウスや、ほかのスプライトに**ふれたら**
- キーが**押されていたら**
- ある**色にふれたら**
- 「ネコから逃げろ」を**本物のゲーム**にする

:::

📷 ここにブロックの画面：「ずっと」の中に「もし マウスのポインター に触れた なら」が入ったスクリプト

---

# 「もし 〜 なら」の形

:::

「**制御**」の「**もし 〜 なら**」には、**六角形の穴**があいているよ。

- 穴の中 … 「〜かどうか」を調べるブロック
- 口の中 … 「**はい**」のときだけ動くブロック

> 「いいえ」のときは、口の中をとばして、下へ進むよ。

:::

📷 ここにブロックの画面：「もし 〜 なら」の六角形の穴と口に印をつけたもの

---

# 六角形のブロック

:::

水色の「**調べる**」には、**六角形**のブロックがあるよ。

- 「**マウスのポインター に触れた**」
- 「**スペース キーが押された**」
- 「**マウスが押された**」

六角形のブロックは、「**はい**」か「**いいえ**」で答えるんだ。

> クリックすると、「true（はい）」か「false（いいえ）」と答えてくれるよ。

:::

📷 ここにブロックの画面：「調べる」の六角形のブロックをクリックして、「false」と出ているところ

---

# マウスにふれたら

:::

1. 緑の旗の下に「**ずっと**」
2. 中に「**もし 〜 なら**」
3. 穴に「**マウスのポインター に触れた**」
4. 口に「**色 の効果を 25 ずつ変える**」

> 「もし」は**1回しか**調べないんだ。「**ずっと**」の中に入れると、何回も調べつづけてくれるよ。

:::

📷 ここにブロックの画面：「ずっと」→「もし マウスのポインター に触れた なら」→「色 の効果を 25 ずつ変える」

---

# でなければ

:::

「**もし 〜 なら / でなければ**」は、口が**2つ**あるブロック。

- 上の口 … 「**はい**」のとき
- 下の口 … 「**いいえ**」のとき

ふれたら色を変えて、はなれたらもとにもどそう。

- 上の口に「**色 の効果を 50 にする**」
- 下の口に「**画像効果をなくす**」

:::

📷 ここにブロックの画面：「もし マウスのポインター に触れた なら / でなければ」に「色 の効果を 50 にする」「画像効果をなくす」

---

# キーでなめらかに動かそう

:::

1. 緑の旗の下に「**ずっと**」
2. 中に「**もし 〜 なら**」を4つならべる
3. 穴に「**右向き矢印 キーが押された**」などを入れる
4. 口に「**x座標を 10 ずつ変える**」などを入れる

> b4 のやりかたより、**なめらか**に動くよ。2人で同時に押しっぱなしにしても、どちらも動くんだ。

:::

📷 ここにブロックの画面：「ずっと」の中に、矢印キー4つの「もし 〜 なら」がならんだスクリプト

---

# ほかのスプライトにふれたら

:::

1. 「**スプライトを選ぶ**」で、2匹目（りんごなど）を出す
2. ネコに「**ずっと**」と「**もし 〜 なら**」を作る
3. 穴に「**マウスのポインター に触れた**」を入れ、▼ で2匹目の名前をえらぶ
4. 口に「**こんにちは! と 2 秒言う**」

> ネコをキーで動かして、2匹目にぶつけてみよう。

:::

📷 ここにブロックの画面：「もし Apple に触れた なら」と、ネコがりんごにふれているステージ

---

# 色にふれたら

:::

「**〇色に触れた**」は、ステージの**色**を調べるブロック。

1. 「**〇色に触れた**」の色の四角をクリック
2. いちばん下の**スポイト**のボタンを押す
3. ステージの、調べたい色をクリック

> 背景に赤い線をかいて「赤にふれたらスタートにもどる」にすると、めいろが作れるよ。

:::

📷 ここにブロックの画面：「〇色に触れた」の色の四角をクリックして、スポイトのボタンが見えているところ

---

# ゲームを終わらせる

:::

「**制御**」の「**すべてを止める**」は、赤いボタンと同じ。**ぜんぶのスクリプト**が止まるよ。

- もし 2匹目にふれたら …「**すべてを止める**」
- もし 赤い色にふれたら …「**すべてを止める**」

> ゲームオーバーのときに使うよ。止める前に「ざんねん！」と言わせてもいいね。

:::

📷 ここにブロックの画面：「もし 〜 に触れた なら」の中に「すべてを止める」

---

# 🎮 ミニゲーム：つかまったら終わり

:::

**🏃 追いかけ** … c1 の「ネコから逃げろ」を、本物のゲームにしよう！

1. 「ずっと」の中に「**もし 〜 なら**」を足す
2. 穴に「**マウスのポインター に触れた**」
3. 口に「**つかまえた! と 1 秒言う**」と「**すべてを止める**」
4. 何秒逃げきれるか、となりの人と勝負！

> つかまると、ネコが止まってくれるね。プログラムが「勝ち負け」を決められるようになったよ。

:::

📷 ここにブロックの画面：「マウスのポインター へ向ける」「3 歩動かす」「もし マウスのポインター に触れた なら（つかまえた! と 1 秒言う・すべてを止める）」

---

# やってみよう

:::

1. マウスにふれたら色が変わる、はなれたらもどる
2. 矢印キーで、なめらかに動かす
3. 背景に線をかいて、線にふれたらスタートにもどる
4. 「つかまったら終わり」で、止まる前に「**終わるまで ニャー の音を鳴らす**」
5. ネコの歩数を変えて、ちょうどよいむずかしさにする

> 次の章では、**得点**や**のこり時間**を数えられるようにするよ。

:::

📷 ここに動いているようす：「つかまえた!」と言っているネコ
