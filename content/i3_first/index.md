# ③ はじめてのプログラム

ブロックをつなげて、ネコを動かそう

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

いよいよ、**自分でプログラム**を作るよ。

- ブロックを**ドラッグ**して置く
- ブロックを**つなげる**
- **緑の旗**で動かす
- 作品を**パソコンに保存**する

> 使うブロックは3つだけ。かんたんだよ！

:::

📷 ここに完成したようす：「緑の旗が押されたとき」→「10 歩動かす」→「15 度回す」の3つがつながったスクリプト

---

# ブロックをクリックしてみよう

:::

1. 「**動き**」をクリック
2. 「**10 歩動かす**」を、まん中の**コードエリア**にドラッグ
3. 置いたブロックを**クリック**
4. ネコが少し右に動いたら成功！

> 動いているあいだ、ブロックのまわりが黄色く光るよ。

:::

📷 ここにブロックの画面：「動き」の中の「10 歩動かす」をコードエリアにドラッグしているところ

---

# 数字を変えよう

:::

1. 「**10 歩動かす**」の白い丸のところをクリック
2. **50** を入れる
3. ブロックをクリック

ネコの動きが**大きく**なったね。

> 数字を大きくすると遠くへ、小さくすると少しだけ動くよ。

:::

📷 ここにブロックの画面：白い丸のところを 50 にした「50 歩動かす」

---

# ブロックをつなげよう

:::

1. 「**動き**」の「**15 度回す**」をえらぶ（右回りの矢印のほう）
2. 「**10 歩動かす**」の**すぐ下**に近づける
3. 灰色の影が出たら、はなす → **カチッ！**
4. つながったブロックをクリック

> ⚠ はずすときは、**下のブロック**を持って引っぱるよ。いらないブロックは、左のブロックのならぶところにもどすと消えるよ。

:::

📷 ここにブロックの画面：「10 歩動かす」の下に「15 度回す」がつながったところ（つなぐときの灰色の影も撮れれば）

---

# 緑の旗で動かそう

:::

1. 「**イベント**」をクリック
2. 「**（緑の旗）が押されたとき**」を、つないだブロックの**上**にのせる
3. ステージの上の**緑の旗**をクリック

> 緑の旗をクリックするたびに、下のブロックが上から順番に動くよ。止めたいときは、となりの**赤いボタン**を押してね。

:::

📷 ここにブロックの画面：「緑の旗が押されたとき」の下に「10 歩動かす」「15 度回す」がつながったスクリプト

---

# 🎮 ミニゲーム：何回で1周？

:::

**🔮 予想** … 先に予想してから、たしかめよう！

緑の旗を**何回**押すと、ネコが**ぐるっと1周**して、もとの向きにもどるかな？

1. 予想した回数を、となりの人に言う
2. 「**10 歩動かす**」の数字を **0** にする
3. 緑の旗を押しながら、回数を数える
4. もとの向きにもどったら、ストップ！

> 予想がいちばん近かった人の勝ち！ 右下の「**向き**」の数字を見ながらやると、わかりやすいよ。

:::

📷 ここに画面：ネコが少しずつ回っているステージ（右下の「向き」の数字が見えるように）

---

# ネコをもとにもどそう

:::

何回も動かすと、ネコがはしっこに行ったり、ななめになったりするね。

1. ステージのネコを**ドラッグ**して、まん中にもどす
2. 右下の「**向き**」をクリック
3. **90** にする → ネコがまっすぐ右を向く

> 次の基本編では、プログラムでもとの場所にもどす方法をおぼえるよ。

:::

📷 ここに画面：右下のスプライトのところで「向き」をクリックして 90 にしているところ

---

# 作品をパソコンに保存しよう

:::

1. 「**ファイル**」をクリック
2. 「**コンピューターに保存する**」をえらぶ
3. ブラウザの右上に、ダウンロードの知らせが出たら OK！

作品は「**ダウンロード**」フォルダに、**Scratchのプロジェクト.sb3** という名前で入るよ。

> ⚠ 何回も保存すると、名前のうしろに (1) (2) と番号がつくよ。番号がいちばん大きいのが、最後に保存したものだよ。

:::

📷 ここに画面：「ファイル」メニューをひらいて「コンピューターに保存する」に印をつけたところと、ブラウザ右上のダウンロードの知らせ

---

# ファイルに名前をつけよう

:::

このままだと、どれが自分の作品かわからなくなるね。わかりやすい名前に変えよう。

1. ダウンロードの知らせの、**フォルダーのマーク**をクリック
2. 保存したファイルを**右クリック**して、名前の変更をえらぶ
3. 作品の名前を入れる（例：**はじめてのネコ.sb3**）

> ⚠ うしろの **.sb3** は消さないでね。消すと Scratch で読み込めなくなるよ。

:::

📷 ここに画面：「ダウンロード」フォルダで、Scratchのプロジェクト.sb3 を右クリックして名前を変えているところ

---

# つづきから作るには

:::

次の日に、保存した作品のつづきを作れるよ。

1. エディターをひらく
2. 「**ファイル**」をクリック
3. 「**Load from your computer**」をえらぶ（ここだけ英語で出るよ）
4. 「ダウンロード」フォルダから、保存した **.sb3** のファイルをえらぶ

> ⚠ 読み込むと、いま画面にある作品と入れかわるよ。だいじな作品は、先に保存しておこう。

:::

📷 ここに画面：「ファイル」メニューの「Load from your computer」に印をつけたところ

---

# やってみよう

:::

ブロックを変えて、ネコの動きをかえてみよう。

1. 歩く数を **100** にする
2. 回る角度を **90** にする
3. 「**10 歩動かす**」を、もう1つつなげる
4. 緑の旗を何回もクリックして、ネコがどう動くか見る
5. できた作品をパソコンに保存する

> これで導入編はおしまい！ 次の基本編では、いろいろなブロックを使っていくよ。

:::
