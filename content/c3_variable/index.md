# ③ 変数をつかおう

得点とのこり時間を数えよう

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

オレンジの「**変数**」のブロックで、ゲームに**数**を持たせよう。

- 変数を**作る**
- **得点**をふやす
- **のこり時間**をへらす
- 10秒で何回クリックできるか**勝負**する

:::

📷 ここに完成したようす：ステージの左上に「得点」と「のこり時間」が表示されているところ

---

# 変数ってなに？

:::

**変数**は、**名前のついた箱**。中に数を入れておけるよ。

- **得点** … 当たるたびに 1 ふえる
- **のこり時間** … 1秒ごとに 1 へる
- **ライフ** … ぶつかるたびに 1 へる

> 箱の中の数は、プログラムで**ふやしたり・へらしたり・決めたり**できるんだ。

:::

📷 ここに画面：「得点」と書いた箱に数が入っているイラスト、またはステージの変数の表示

---

# 変数を作ろう

:::

1. 「**変数**」をクリック
2. 「**変数を作る**」をクリック
3. 「**新しい変数名:**」に **得点** と入れる
4. 「**すべてのスプライト用**」のまま「**OK**」

ブロックのならぶところに「**得点**」のブロックがふえたね。

:::

📷 ここに画面：「新しい変数」の画面で、名前に「得点」と入れたところ

---

# ステージに表示する

:::

「**得点**」のブロックの左に、**チェックボックス**があるよ。

- チェックあり … ステージに「得点」が出る
- チェックなし … かくれる

> ゲームをする人に見せたい数は、チェックを入れておこう。

:::

📷 ここに画面：変数のチェックボックスと、ステージの左上に出た「得点 0」

---

# クリックで得点

:::

1. 緑の旗の下に「**得点 を 0 にする**」
2. 「**このスプライトが押されたとき**」の下に「**得点 を 1 ずつ変える**」
3. 緑の旗を押してから、ネコをクリック

> ブロックの「変数」のところは、▼ で「**得点**」にかえてね。はじめに 0 にしておかないと、前の得点がのこったままになるよ。

:::

📷 ここにブロックの画面：「緑の旗が押されたとき」→「得点 を 0 にする」と、「このスプライトが押されたとき」→「得点 を 1 ずつ変える」

---

# のこり時間

:::

もう1つ、「**のこり時間**」という変数を作ろう。

1. 緑の旗のスクリプトに「**のこり時間 を 10 にする**」
2. その下に「**10 回繰り返す**」
3. 中に「**1 秒待つ**」と「**のこり時間 を -1 ずつ変える**」
4. くりかえしの下に「**すべてを止める**」

> 10秒たつと、ゲームが止まるよ。

:::

📷 ここにブロックの画面：のこり時間のスクリプト（10 にする → 10 回繰り返す（1 秒待つ・-1 ずつ変える）→ すべてを止める）

---

# 変数でくらべる

:::

「**演算**」の「**〇 = 〇**」で、変数の数をくらべられるよ。

1. 「**得点 を 1 ずつ変える**」の下に「**もし 〜 なら**」
2. 穴に「**〇 = 〇**」を入れる
3. 左に「**得点**」のブロック、右に **10** を入れる
4. 口に「**やったね! と 2 秒言う**」

> 「**〇 > 〇**」（より大きい）「**〇 < 〇**」（より小さい）もあるよ。

:::

📷 ここにブロックの画面：「もし 得点 = 10 なら」→「やったね! と 2 秒言う」

---

# 🎮 ミニゲーム：10秒連打勝負

:::

**⚔ 勝負** … 10秒で、ネコを何回クリックできるかな？

1. 「クリックで得点」と「のこり時間」のスクリプトを用意する
2. 緑の旗を押したら、スタート！
3. 止まったときの「**得点**」が自分の記録
4. となりの人と交代して、記録をくらべる

> 自分の**いちばんよい記録**をおぼえておこう。何回やったら記録をこえられるかな？

:::

📷 ここに画面：ゲームが終わって、「得点」と「のこり時間 0」が表示されているステージ

---

# やってみよう

:::

1. のこり時間を **30秒** にする
2. 得点が10になったら「やったね!」と言う
3. クリックするたびに、「**ピッチ の効果を 10 ずつ変える**」で鳴き声を高くする
4. 「すべてを止める」の前で、得点を言わせる
5. 「ライフ」の変数を作って、ステージに表示する

> 「**こんにちは! と 2 秒言う**」の白いところに「**得点**」のブロックを入れると、得点をしゃべるよ。

:::

📷 ここにブロックの画面：「得点 と 2 秒言う」
