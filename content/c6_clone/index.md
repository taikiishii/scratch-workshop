# ⑥ クローンでふやそう

同じスプライトを、たくさんふやそう

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

**クローン**を使うと、同じスプライトをプログラムで**たくさん**ふやせるよ。

- クローンを**作る**
- クローンだけを**動かす**
- クローンを**消す**
- 雪をふらせて、**クリックで消す**ゲームにする

:::

📷 ここに完成したようす：雪のクローンがたくさんふっているステージ

---

# クローンってなに？

:::

**クローン**は、プログラムで作る**コピー**。

- もとのスプライトを「**本体**」という
- クローンは、本体と**同じ絵・同じ場所**で生まれる
- 赤いボタンで止めると、クローンは**ぜんぶ消える**

> 右下のスプライトの一覧には出てこないよ。プログラムが動いているあいだだけいるんだ。

:::

📷 ここに画面：本体とクローンが少しずれてならんでいるステージ

---

# クローンを作ろう

:::

1. 「**制御**」の「**自分自身 のクローンを作る**」をクリック
2. ……何も変わらないように見えるね
3. ステージのネコを**ドラッグ**してみよう
4. 下に、もう1匹いた！

> クローンは本体と**同じ場所**に生まれるから、ぴったり重なって見えないんだ。

:::

📷 ここに画面：ネコをドラッグして、下からクローンが出てきたところ

---

# クローンだけを動かす

:::

1. 「**クローンされたとき**」を置く
2. 下に「**どこかの場所 へ行く**」をつなぐ
3. 「**自分自身 のクローンを作る**」を何回かクリック

> 「**クローンされたとき**」の下は、**クローンだけ**が動くよ。本体は動かないんだ。

:::

📷 ここにブロックの画面：「クローンされたとき」→「どこかの場所 へ行く」と、ちらばったネコ

---

# たくさんふやす

:::

1. 緑の旗の下に「**10 回繰り返す**」
2. 中に「**自分自身 のクローンを作る**」と「**0.5 秒待つ**」
3. 緑の旗をクリック

0.5秒ごとに、ネコがふえていくよ。

> 「クローンされたとき」のスクリプトも、そのままのこしておいてね。

:::

📷 ここにブロックの画面：「10 回繰り返す」の中に「自分自身 のクローンを作る」「0.5 秒待つ」

---

# 本体は隠しておく

:::

本体がステージにのこっていると、じゃまなことがあるね。

1. 緑の旗のすぐ下に「**隠す**」をつなぐ
2. 「**クローンされたとき**」の下に「**表示する**」をつなぐ

> クローンは、本体の「隠す」も**まねして**生まれるよ。だから、クローンのほうで「表示する」が要るんだ。

:::

📷 ここにブロックの画面：「緑の旗が押されたとき」→「隠す」と、「クローンされたとき」→「表示する」

---

# クローンを消す

:::

「**このクローンを削除する**」で、クローンを消せるよ。

1. 「**クローンされたとき**」のスクリプトの最後に「**2 秒待つ**」
2. その下に「**このクローンを削除する**」

> ⚠ クローンは**300個まで**しか作れないよ。いらなくなったクローンは、消しておこう。

:::

📷 ここにブロックの画面：「クローンされたとき」→ … →「2 秒待つ」→「このクローンを削除する」

---

# 雪をふらせよう

:::

b5 で、白い丸の「**雪**」スプライトをかこう。背景は暗い色にしよう。

**本体**：緑の旗 →「**隠す**」→「**ずっと**」の中で「**自分自身 のクローンを作る**」「**0.3 秒待つ**」

**クローン**：「**クローンされたとき**」→ x を **-220 から 220 までの乱数**、y を **170** にする →「**表示する**」→「**70 回繰り返す**」の中で「**y座標を -5 ずつ変える**」→「**このクローンを削除する**」

:::

📷 ここにブロックの画面：雪の本体とクローンの2つのスクリプト

---

# 🎮 ミニゲーム：雪つぶしゲーム

:::

**⚔ 勝負** … 10秒で、雪をいくつ消せるかな？

1. 雪に「**このスプライトが押されたとき**」を作る
2. 下に「**得点 を 1 ずつ変える**」と「**このクローンを削除する**」
3. ステージに、c3 の「**のこり時間**」のスクリプトを作る（「**得点 を 0 にする**」も入れる）
4. 緑の旗でスタート！ となりの人と記録をくらべよう

> クリックされたクローンだけが消えるよ。クローンも、本体と**同じスクリプト**を持っているんだ。

:::

📷 ここに画面：雪がふっていて、「得点」と「のこり時間」が表示されているステージ

---

# やってみよう

:::

1. 雪の大きさを、**乱数**で1つずつ変える
2. 落ちる速さを、**乱数**で1つずつ変える
3. 雪をクリックしたら、音を鳴らす
4. 雪のかわりに、星やりんごを落とす
5. 雪つぶしゲームの、自分の最高記録をめざす

> これで制御編はおしまい！ 次のゲーム編では、ここまでのブロックで**いろいろなゲーム**を作るよ。

:::
