# Scratch ってなに？

:::

Scratch は、**ブロックをつなげて**プログラムを作る道具だよ。

- 文字を打たなくても、**ドラッグでつなぐ**だけ
- パソコンの**ブラウザ**で動く
- ずっと**無料**で使える
- 70 以上の**ことば**に対応している

> アメリカの MIT という大学で生まれて、いまは Scratch 財団がつくっているよ。世界中の子どもたちが使っているんだ。

:::

📷 ここに画面：ブロックがいくつかつながったスクリプトの例（「動き」「見た目」など色のちがうブロックがまざったもの）

---

# プログラムってなに？

:::

**プログラム**は、コンピューターへの「**やることの順番**」だよ。

たとえば、朝のしたく。

1. 顔をあらう
2. 着がえる
3. 朝ごはんを食べる

順番をまちがえると、パジャマのまま出かけちゃうね。

> Scratch では、**ブロック1つが指示1つ**。上から順番に動くよ。

:::

📷 ここに画面：上から3つ縦につながったスクリプト（例：「緑の旗が押されたとき」→「10 歩動かす」→「こんにちは! と 2 秒言う」）

---

# どんなものが作れるの？

:::

Scratch では、いろいろな作品が作れるよ。

- **ゲーム** … よける・あてる・めいろ
- **アニメ** … キャラクターが動く
- **おはなし** … 会話で進む紙しばい
- **音楽** … 楽器をえんそう
- **お絵かき** … ペンで模様をかく

> このワークショップの最後には、**自分だけの作品**を作って発表するよ。

:::

📷 ここに画面：ゲーム・アニメ・おはなしなど、ジャンルのちがう作品のステージを2〜3枚ならべたもの

---

# 作品であそんでみよう

:::

ほかの人が作った作品を動かしてみよう。

1. メンターが教えてくれる作品をひらく
2. **緑の旗**をクリックしてスタート
3. **赤い丸**のボタンで止める

> 大きな画面であそびたいときは、ステージの右上の「**全画面表示**」ボタンを押してね。

:::

📷 ここに画面：作品ページのステージ部分（緑の旗・赤い停止ボタン・全画面表示ボタンに印をつける）

---

# 「中を見る」でのぞいてみよう

:::

その作品が、**どんなプログラムで動いているか**をのぞけるよ。

1. 作品ページの「**中を見る**」をクリック
2. 右上のスプライトをクリックして、左のブロックを見る

> ⚠ 見るだけにしておこう。ここで変えても、もとの作品は変わらないよ。

:::

📷 ここに画面：作品ページの「中を見る」ボタン（印をつける）と、ひらいたあとのエディター

---

# このワークショップでやること

:::

順番に進むと、自分の作品が作れるようになるよ。

1. **導入編** … 画面を知って、はじめてのプログラム
2. **基本編** … 動き・見た目・音・イベント
3. **制御編** … くりかえし・もしも・変数
4. **ゲーム編** … あそべるゲームを作る
5. **拡張機能編** … ペン・音楽・カメラ
6. **作品編** … 自分だけの作品を発表

> 次の章では、Scratch の**画面の見かた**をおぼえるよ。

:::
