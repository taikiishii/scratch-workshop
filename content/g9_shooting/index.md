# なにをするの？

:::

スペースキーで弾をうって、やってくる敵をうちおとそう。

> このゲームのポイントは「**クローンでふやす**」だよ。

:::

# このゲームのしくみ

:::

1. スペースキーを押すと、弾がクローンで出てくる
2. 敵が上からやってくる
3. 弾が敵に当たったら得点

> 💪 敵の種類をふやしてみよう。

:::
