# ② 連打レース

パターン：2人で対戦

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

2人でキーを**連打**して、先にゴールした方の勝ち。

- 1台のパソコンで、**2人**であそぶ
- キーを押すたびに、少しずつ進む
- ゴールの線に先についた方の勝ち

> このゲームのポイントは「**2人で対戦**」だよ。

:::

📷 ここに画面：完成した連打レース（2匹のキャラクターと、右はしの赤いゴールの線）

---

# このゲームのしくみ

:::

**登場するもの**

- **ネコ** … 1人目。**a** キーで進む
- **2匹目** … 2人目。**l**（エル）キーで進む
- **背景** … 右はしに、赤いゴールの線

**ルール**

1. キーを1回押すと、10歩進む
2. 赤い線に先にふれた方の勝ち

> ⚠ キーの**押しっぱなしは反則**！ 1回ずつトントン押そう。

:::

📷 ここに画面：キーボードの a キーと l キーに印をつけた写真

---

# じゅんび

:::

1. 「**スプライトを選ぶ**」で、2匹目のキャラクターを出す
2. 右下の「**ステージ**」をえらび、「**背景**」タブをひらく
3. 「**四角形**」で、右はしにたての**赤い線**をかく
4. 「**直線**」で、まん中によこの線をかくと、コースらしくなるよ

> 赤い線は、ほかのところで使わない色にしよう。

:::

📷 ここに画面：右はしに赤いゴールの線をかいた背景

---

# ネコ：a キーで進む

:::

**スクリプト①**：緑の旗 →「**x座標を -200 、y座標を 60 にする**」

**スクリプト②**

1. 「**a キーが押されたとき**」
2. 「**10 歩動かす**」→「**次のコスチュームにする**」
3. 「**もし 〇色に触れた なら**」の色を、スポイトで赤い線にする
4. 口に「**ネコの勝ち! と 2 秒言う**」→「**すべてを止める**」

:::

📷 ここにブロックの画面：ネコの2本のスクリプト

---

# 2匹目：l キーで進む

:::

ネコのスクリプトを、2匹目に**コピー**しよう。

1. ネコのスクリプトを、右下の2匹目の上まで**ドラッグ**してはなす
2. 2匹目をクリックして、コピーされたのをたしかめる
3. キーを「**l**」に、y座標を **-60** に変える
4. セリフを「**〇〇の勝ち!**」に変える

> スクリプトを、ほかのスプライトの上にはなすと**コピー**できるんだ。

:::

📷 ここにブロックの画面：2匹目のスクリプト（l キー・y座標 -60）

---

# 🎮 あそんで勝負しよう

:::

**⚔ 勝負** … となりの人と、3回勝負！

1. 緑の旗で、スタートの場所にならべる
2. 「よーい、ドン！」の合図で連打スタート
3. 先にゴールした方が1勝
4. キーを交代して、もう一度

> 合図は、まわりの人に言ってもらおう。押しっぱなしをしていないか、見ていてもらうといいよ。

:::

📷 ここに画面：ネコがゴールして「ネコの勝ち!」と言っているステージ

---

# 💪 改造してみよう

:::

1. 3人目のキャラクターを足す（キーは別のものに）
2. 1回で進む歩数を変えて、コースの長さを調整する
3. ゴールしたら、勝った音を鳴らす
4. 背景にじゃまな色をかいて、ふれたら**スタートにもどる**ようにする
5. ステージに「よーい、ドン!」のスクリプトを作る（メッセージを使おう）

:::
