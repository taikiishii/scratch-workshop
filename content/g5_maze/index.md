# ⑤ めいろゲーム

パターン：色で当たりを調べる

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

自分でかいた**めいろ**を、ゴールまで進もう。

- めいろは、背景に**自分でかく**
- **黒いかべ**にふれたら、スタートにもどる
- **赤いゴール**についたら、クリア

> このゲームのポイントは「**色で当たりを調べる**」だよ。

:::

📷 ここに画面：完成しためいろゲーム（黒いかべのめいろ、左下に小さな丸、右上に赤いゴール）

---

# このゲームのしくみ

:::

**登場するもの**

- **プレイヤー** … 小さな丸。矢印キーで動く
- **背景** … 黒いかべのめいろと、赤いゴール
- **ステージ** … かかった時間を数える

**ルール**

1. 黒い色にふれたら、スタートにもどる
2. 赤い色にふれたら、ゴール！

:::

📷 ここに画面：プレイヤー・かべ・ゴールに、それぞれの役わりを書きこんだもの

---

# じゅんび：めいろをかく

:::

1. 右下の「**ステージ**」→「**背景**」タブをひらく
2. 左下の「**ビットマップに変換**」をクリック
3. 「**四角形**」で、**黒いかべ**をかく
4. 右上に、**赤いゴール**の四角をかく
5. 左下は、スタートのためにあけておく

> 道は、プレイヤーが通れるくらい**広め**にかこう。

:::

📷 ここに画面：背景のペイントエディターで、黒いかべと赤いゴールをかいたところ

---

# じゅんび：プレイヤーをかく

:::

1. 「**スプライトを選ぶ**」の「**描く**」で、新しいスプライトを出す
2. 「**円**」で、**青い小さな丸**をかく
3. 名前の欄を「**プレイヤー**」にする
4. ネコは、右クリックして「**削除**」
5. 変数「**タイム**」を作る

> ⚠ プレイヤーには、**黒と赤を使わない**でね。

:::

📷 ここに画面：小さな青い丸のプレイヤーと、スプライトの名前の欄

---

# プレイヤー：矢印キーで動く

:::

1. 緑の旗 →「**x座標を -210 、y座標を -150 にする**」
2. 「**ずっと**」の中に「**もし 〜 なら**」を4つ
3. 矢印キーそれぞれで、x か y を **3** ずつ変える

> かべの中に入りこまないように、1回に動く数は**小さめ**にしよう。

:::

📷 ここにブロックの画面：プレイヤーの、矢印キーのスクリプト

---

# プレイヤー：色を調べる

:::

もう1本、緑の旗のスクリプトを作ろう。

1. 「**ずっと**」の中に「**もし 〇色に触れた なら**」を2つ
2. 1つ目の色は、スポイトで**黒いかべ**に
3. 口に、スタートの場所にもどすブロック
4. 2つ目の色は**赤いゴール**に
5. 口に「**ゴール! と 2 秒言う**」→「**すべてを止める**」

:::

📷 ここにブロックの画面：プレイヤーの、色を調べるスクリプト

---

# ステージ：タイム

:::

1. ステージをえらんで、緑の旗 →「**タイム を 0 にする**」
2. 「**ずっと**」の中に「**1 秒待つ**」と「**タイム を 1 ずつ変える**」

> ゴールで「すべてを止める」と、タイムも止まるよ。

:::

📷 ここにブロックの画面：ステージのタイムのスクリプト

---

# 🎮 あそんで勝負しよう

:::

**⚔ 勝負** … となりの人の、めいろにちょうせん！

1. 席を交代して、となりの人のめいろであそぶ
2. ゴールしたときの「**タイム**」が記録
3. 自分のめいろでも、タイムをはかる
4. 速くゴールできた方の勝ち！

> むずかしすぎるめいろは、ゴールできないかも。ちょうどよいむずかしさにしよう。

:::

📷 ここに画面：ゴールして「ゴール!」と言っているプレイヤーと「タイム」

---

# 💪 改造してみよう

:::

1. 2つ目のめいろ（背景）を作って、ゴールしたら次の面へ
2. かべにふれたら音を鳴らす
3. 黄色い「**近道**」の色を作って、ふれたらワープする
4. めいろの中を行ったり来たりする**おじゃまキャラ**を足す
5. タイムが30をこえたら、ゲームオーバーにする

:::

📷 ここに画面：おじゃまキャラがいるめいろ
