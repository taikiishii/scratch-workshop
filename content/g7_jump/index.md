# ⑦ ジャンプゲーム

パターン：ジャンプでよける

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

右から走ってくる**しょうがいぶつ**を、**ジャンプ**でとびこえよう。

- **スペースキー**でジャンプ
- とびこえたら**得点**
- ふれたら、**ゲームオーバー**

> このゲームのポイントは「**ジャンプでよける**」だよ。

:::

📷 ここに画面：完成したジャンプゲーム（ジャンプしているネコと、右から来るしょうがいぶつ）

---

# このゲームのしくみ

:::

**登場するもの**

- **ネコ** … スペースキーでジャンプする
- **しょうがいぶつ** … 右から左へ流れてくる

**ルール**

1. しょうがいぶつが、ランダムな間をあけてやってくる
2. 左はしまで行ったら得点が 1 ふえて、また右から来る
3. ネコにふれたら、ゲームオーバー

:::

📷 ここに画面：ネコとしょうがいぶつに、それぞれの役わりを書きこんだもの

---

# じゅんび

:::

1. 「**描く**」で、しょうがいぶつ（**四角いブロック**など）をかく
2. 名前の欄を「**しょうがいぶつ**」にする
3. ネコの名前の欄を「**ネコ**」にする
4. 背景に、**地面**をかく
5. 変数「**得点**」を作る

:::

📷 ここに画面：地面のある背景と、ネコ・しょうがいぶつ

---

# ネコ：ジャンプ

:::

1. 緑の旗 →「**x座標を -150 、y座標を -100 にする**」
2. 「**ずっと**」の中に「**もし スペース キーが押された なら**」
3. 口に「**10 回繰り返す**」→ 中に「**y座標を 15 ずつ変える**」
4. その下にもう1つ「**10 回繰り返す**」→ 中に「**y座標を -15 ずつ変える**」

> 10回上がって、10回下りる。だから、ちゃんと**もとの高さ**にもどるんだ。

:::

📷 ここにブロックの画面：ネコのジャンプのスクリプト

---

# しょうがいぶつ：走ってくる

:::

1. 緑の旗 →「**得点 を 0 にする**」→「**ずっと**」
2. 「**x座標を 240 、y座標を -110 にする**」→「**表示する**」
3. 「**60 回繰り返す**」の中に「**x座標を -8 ずつ変える**」と「**もし ネコ に触れた なら**」（ざんねん!・すべてを止める）
4. くりかえしの下に、得点を 1 ふやす →「**隠す**」→「**（0.5 から 2 までの乱数） 秒待つ**」

> 8 × 60 = 480。ステージの横はばと同じだけ進むよ。

:::

📷 ここにブロックの画面：しょうがいぶつのスクリプト

---

# 高さを合わせよう

:::

ネコとしょうがいぶつが、**地面の上**に立つように合わせよう。

1. ステージで、ネコとしょうがいぶつを地面の上までドラッグ
2. 右下の「**y**」の数字を見る
3. その数を、スクリプトの y の数に入れる

> ジャンプしてもとびこえられないときは、ジャンプの「**15**」を大きくしてみよう。

:::

📷 ここに画面：地面の上に立ったネコと、右下の「y」の数字

---

# 🎮 あそんで勝負しよう

:::

**⚔ 勝負** … 何回とびこえられるかな？

1. 緑の旗でスタート
2. ゲームオーバーになったときの「**得点**」が記録
3. となりの人と交代して、記録をくらべる
4. 3回やって、いちばんよい記録で勝負！

:::

📷 ここに画面：ゲームオーバーになったステージと「得点」

---

# 💪 改造してみよう

:::

1. 得点が上がるほど、しょうがいぶつを速くする
2. 空を飛ぶしょうがいぶつを足す（ジャンプするとぶつかる！）
3. ジャンプのときに、音を鳴らす
4. 背景の雲や山を、ゆっくり流す
5. ジャンプのあいだだけ、ネコのコスチュームを変える

:::
