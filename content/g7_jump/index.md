# なにをするの？

# このゲームのしくみ

:::

1. しょうがいぶつが右から左へ流れてくる
2. スペースキーで上がって、下りてくる
3. ふれたらゲームオーバー

> 💪 空を飛ぶしょうがいぶつも足してみよう。

:::
