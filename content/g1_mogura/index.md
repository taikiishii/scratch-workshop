# ① もぐらたたき

パターン：クリックで得点

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

あちこちに出てくるキャラクターを、**クリック**してつかまえよう。

- 出てくる場所は、毎回ちがう
- クリックできたら**得点**
- **30秒**でおしまい

> このゲームのポイントは「**クリックで得点**」だよ。

:::

📷 ここに画面：完成したもぐらたたき（キャラクターが出ていて、「得点」「のこり時間」が見えるステージ）

---

# このゲームのしくみ

:::

**登場するもの**

- **もぐら** … 出たり隠れたりする（好きなキャラクターでOK）
- **ステージ** … のこり時間を数える

**ルール**

1. もぐらが、ランダムな場所に出てくる
2. クリックされたら得点が 1 ふえて、すぐ隠れる
3. 30秒たったらおしまい

:::

📷 ここに画面：もぐらとステージに、それぞれの役わりを書きこんだもの

---

# じゅんび

:::

1. 「**スプライトを選ぶ**」で、もぐらにするキャラクターを出す
2. ネコは、右下で右クリックして「**削除**」
3. 「**背景を選ぶ**」で、好きな背景をえらぶ
4. 変数「**得点**」と「**のこり時間**」を作る

> もぐらは、少し小さめ（「**大きさ**」を 60 くらい）にするとむずかしくなるよ。

:::

📷 ここに画面：もぐらのスプライトと背景をえらんだあとのエディター

---

# もぐら：出たり隠れたり

:::

c4 で作った「出たり隠れたり」と同じだよ。

1. 緑の旗 →「**得点 を 0 にする**」→「**ずっと**」
2. 「ずっと」の中に「**隠す**」
3. 「**（0.5 から 1.5 までの乱数） 秒待つ**」
4. x を **-200〜200**、y を **-140〜140** の乱数にする
5. 「**表示する**」→「**1 秒待つ**」

:::

📷 ここにブロックの画面：もぐらの「緑の旗が押されたとき」のスクリプト

---

# もぐら：クリックで得点

:::

1. 「**このスプライトが押されたとき**」を置く
2. 下に「**得点 を 1 ずつ変える**」
3. 「**… の音を鳴らす**」で、たたいた音を鳴らす
4. 最後に「**隠す**」

> クリックしたらすぐ隠れるから、**同じもぐらを2回たたけない**よ。

:::

📷 ここにブロックの画面：もぐらの「このスプライトが押されたとき」のスクリプト

---

# ステージ：のこり時間

:::

c3 で作ったタイマーを、**ステージ**に作ろう。

1. 右下の「**ステージ**」をクリック
2. 緑の旗 →「**のこり時間 を 30 にする**」
3. 「**30 回繰り返す**」の中に「**1 秒待つ**」と「**のこり時間 を -1 ずつ変える**」
4. くりかえしの下に「**すべてを止める**」

:::

📷 ここにブロックの画面：ステージの、のこり時間のスクリプト

---

# 🎮 あそんで勝負しよう

:::

**⚔ 勝負** … 30秒で、何点とれるかな？

1. 緑の旗でスタート
2. 止まったときの「**得点**」が記録
3. となりの人と交代して、記録をくらべる
4. 3回やって、いちばんよい記録で勝負！

> 記録を紙にメモしておくと、あとでくらべやすいよ。

:::

📷 ここに画面：ゲームが終わったステージ（「得点」と「のこり時間 0」）

---

# 💪 改造してみよう

:::

1. 出ている時間を **0.7 秒** にして、むずかしくする
2. もぐらを**2匹**にする（スプライトを右クリックして「**複製**」）
3. たたいたら「**色 の効果**」を変えてから隠れる
4. 30秒たったら、得点を言わせる
5. 背景を自分でかいて、もぐらの穴を作る

:::
