# なにをするの？

:::

あちこちに出てくるキャラクターを、クリックしてつかまえよう。

> このゲームのポイントは「**クリックで得点**」だよ。

:::

# このゲームのしくみ

:::

1. キャラクターがランダムな場所に出てくる
2. クリックされたら得点が1ふえる
3. 時間が来たらおしまい

> 💪 出てくる時間を短くして、むずかしくしてみよう。

:::
