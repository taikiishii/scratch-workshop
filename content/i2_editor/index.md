# ② 画面の見かたをおぼえよう

どこに何があるかを知ろう

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

プログラムを作る画面を**エディター**というよ。

この章でおぼえること。

- エディターの**ひらきかた**
- 言語を「**日本語**」にする
- **ステージ**と**スプライト**
- **ブロック**のならぶところと、置くところ

:::

📷 ここに画面：エディターの画面全体（ひらいた直後、ネコがいる状態）

---

# エディターをひらこう

:::

1. ブラウザをひらく
2. 下のアドレスを入れる
3. ネコがいる画面が出たら OK！

```
https://scratch.mit.edu/projects/editor/
```

> Scratch のトップページの「**作る**」からもひらけるよ。

:::

📷 ここに画面：エディターをひらいた直後の画面（アドレスバーも入れる）

---

# 言語を「日本語」にしよう

:::

1. 上のメニューの「**設定**」をクリック
2. 「**言語**」をえらぶ
3. 「**日本語**」をクリック

> ⚠ 「**にほんご**」（ひらがな）もあるけど、この教材は漢字の「**日本語**」にそろえているよ。

:::

📷 ここに画面：「設定」→「言語」をひらいて、「日本語」と「にほんご」がならんでいるところ（「日本語」に印）

---

# 画面の全体を見てみよう

:::

エディターは、大きく **5つ** に分かれているよ。

1. **メニュー** … 保存や設定
2. **ブロックのならぶところ** … 使えるブロック
3. **コードエリア** … ブロックを置くところ
4. **ステージ** … 作品が動くところ
5. **スプライトのならぶところ** … 登場するキャラクター

:::

📷 ここに画面：エディター全体に ①〜⑤ の番号と枠をつけたもの

---

# ステージ

:::

**ステージ**は、作品が動く**舞台**だよ。右上にある。

- **緑の旗** … プログラムをスタート
- **赤いボタン** … ぜんぶ止める
- **全画面表示** … ステージを大きくする

> 緑の旗は、作品をはじめる「**よーい、ドン！**」の合図なんだ。

:::

📷 ここに画面：ステージの上の部分（緑の旗・赤い停止ボタン・全画面表示ボタンに印）

---

# スプライトとステージ

:::

**スプライト**は、ステージに出てくる**役者**。はじめはネコがいるよ。

- **スプライト** … ネコの名前
- **x・y** … ステージのどこにいるか
- **大きさ** … 100 がふつうの大きさ
- **向き** … どっちを向いているか

> スプライトはいくつでもふやせるよ。右下の「**スプライトを選ぶ**」から。

:::

📷 ここに画面：右下のスプライトのならぶところ（名前・x・y・大きさ・向き、「スプライトを選ぶ」ボタンに印）

---

# ブロックのカテゴリー

:::

ブロックは、**色ごと**に分かれているよ。

- 「**動き**」… 青
- 「**見た目**」… むらさき
- 「**音**」… ピンク
- 「**イベント**」… 黄色
- 「**制御**」… オレンジ
- 「**調べる**」… 水色
- 「**演算**」… 緑
- 「**変数**」… こいオレンジ
- 「**ブロック定義**」… 赤

:::

📷 ここに画面：左はしのカテゴリーの丸がならんでいるところ（9色）

---

# 3つのタブ

:::

左上の **タブ** で、作るものを切りかえるよ。

- 「**コード**」… プログラム
- 「**コスチューム**」… 見た目の絵
- 「**音**」… 鳴らす音

> 右下で「**ステージ**」をえらんでいるときは、「コスチューム」のタブが「**背景**」に変わるよ。

:::

📷 ここに画面：左上の「コード」「コスチューム」「音」タブ（印をつける）

---

# 🎮 ミニゲーム：場所あて早押し

**⚔ 勝負** … メンターが言った場所を、先に**指でさした**人の勝ち！

- 緑の旗
- 赤いボタン
- ネコの「**大きさ**」
- 「**イベント**」のブロック
- 「**音**」のタブ
- 「**スプライトを選ぶ**」
- 「**設定**」

> 何問とれたか数えておこう。全部わかったら、エディターの画面はばっちりだよ！
