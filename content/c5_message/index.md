# ⑤ メッセージを送ろう

スプライトどうしで、合図を送りあおう

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

**メッセージ**を使うと、スプライトどうしで**合図**を送りあえるよ。

- 合図を**送る**・**受け取る**
- 2匹で**会話**させる
- 合図で**場面**を変える

> お話やゲームで、みんなが**タイミングを合わせて**動けるようになるよ。

:::

📷 ここに完成したようす：2匹のスプライトが順番にしゃべっているステージ

---

# メッセージってなに？

:::

**メッセージ**は、ステージ全体に聞こえる「**合図**」。

- 送る人 … 「**〇〇 を送る**」
- 受け取る人 … 「**〇〇 を受け取ったとき**」

> 合図は、**ぜんぶのスプライトとステージ**に届くよ。受け取るスクリプトがあるところだけが動くんだ。

:::

📷 ここに画面：1つのスプライトから、ほかのスプライトとステージへ矢印がのびている図

---

# 送る・受け取る

:::

1. 「**イベント**」の「**メッセージ1 を送る**」を置く
2. ▼ をクリックして「**新しいメッセージ**」をえらぶ
3. 名前（例：**あいさつ**）を入れて「**OK**」
4. 「**メッセージ1 を受け取ったとき**」も、▼ で「**あいさつ**」にする

> メッセージの名前は、何をする合図なのかがわかる名前にしよう。

:::

📷 ここにブロックの画面：「メッセージ1 を送る」の ▼ をひらいて「新しいメッセージ」が見えているところ

---

# 2匹で会話しよう

:::

**ネコ**のスクリプト

1. 緑の旗の下に「**こんにちは! と 2 秒言う**」
2. その下に「**あいさつ を送る**」

**2匹目**のスクリプト

1. 「**あいさつ を受け取ったとき**」
2. その下に「**やあ! と 2 秒言う**」

> ネコが話し終わってから、2匹目が答えるね。

:::

📷 ここにブロックの画面：ネコと2匹目のスクリプトを左右にならべたもの

---

# 🎮 ミニゲーム：しゃべる順番を予想

:::

**🔮 予想** … どっちが先にしゃべるかな？

1. ネコのスクリプトを「**あいさつ を送る**」→「**ぼくはネコ と 2 秒言う**」の順にする
2. どっちが先にしゃべるか予想する（ネコ・2匹目・同時）
3. 緑の旗で、たしかめる
4. 次に「送る」を「**あいさつ を送って待つ**」に変えて、もう一度予想！

> 2回とも当たったら、メッセージ名人だよ。

:::

📷 ここにブロックの画面：「あいさつ を送る」→「ぼくはネコ と 2 秒言う」

---

# 「送って待つ」のひみつ

:::

- 「**あいさつ を送る**」… 送ったら、**すぐ次**へ進む
- 「**あいさつ を送って待つ**」… 受け取った人が**終わるまで**待つ

> b3 の「**ニャー の音を鳴らす**」と「**終わるまで ニャー の音を鳴らす**」のちがいと、同じだね。

:::

📷 ここにブロックの画面：「あいさつ を送る」と「あいさつ を送って待つ」を左右にならべたもの

---

# ステージも受け取れる

:::

合図で、**場面**を変えよう。

1. 右下の「**ステージ**」をえらび、背景を2つにする
2. ステージに「**場面2 を受け取ったとき**」を作る
3. その下に「**背景を … にする**」をつなぎ、2つ目の背景をえらぶ
4. ネコが話し終わったら「**場面2 を送る**」

> お話の**紙しばい**が作れるね。

:::

📷 ここにブロックの画面：ステージの「場面2 を受け取ったとき」→「背景を … にする」

---

# ゲームオーバーの合図

:::

c2 の「つかまったら終わり」に、合図を使ってみよう。

1. つかまったら「**ゲームオーバー を送る**」→「**このスクリプトを止める**」
2. ステージは、受け取ったら背景を変える
3. ネコは、受け取ったら「**ざんねん! と 2 秒言う**」→「**すべてを止める**」

> 「このスクリプトを止める」がないと、ふれているあいだ合図を送りつづけてしまうよ。

:::

📷 ここにブロックの画面：「ゲームオーバー を送る」と、ステージ・ネコの「ゲームオーバー を受け取ったとき」

---

# やってみよう

:::

**3つの場面**の紙しばいを作ろう。

1. 背景を3つ用意する
2. 2匹のスプライトに、会話をさせる
3. 会話が終わったら、合図で次の場面に変える
4. 場面ごとに、スプライトの場所や見た目を変える
5. 最後の場面で「おしまい」と言わせる

:::

📷 ここに動いているようす：紙しばいの3つの場面をならべたもの
