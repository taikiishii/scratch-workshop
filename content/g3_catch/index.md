# ③ キャッチゲーム

パターン：落ちてくるものを受けとめる

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

上から落ちてくるものを、左右に動いて受けとめよう。

> このゲームのポイントは「**落ちてくるものを受けとめる**」だよ。

:::

📷 ここに画面：完成したキャッチゲーム

---

# このゲームのしくみ

:::

1. りんごが上から落ちてくる
2. かごを矢印キーで左右に動かす
3. 受けとめたら得点、また上から落ちてくる

> 💪 落ちる速さを、得点が上がるほど速くしてみよう。

:::
