# ⑥ ピンポン

パターン：はね返る

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

はね返るボールを、バーで打ち返そう。落としたらおしまい。

> このゲームのポイントは「**はね返る**」だよ。

:::

📷 ここに画面：完成したピンポン

---

# このゲームのしくみ

:::

1. ボールが動きつづけて、はしではね返る
2. バーをマウスで左右に動かす
3. バーに当たったらはね返り、下に落ちたらおしまい

> 💪 打ち返すたびにボールを速くしてみよう。

:::
