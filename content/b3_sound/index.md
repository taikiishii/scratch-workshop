# ③ 音を鳴らそう（音）

鳴らす・えらぶ・録音する

*Scratch 体験ワークショップ*

---

# なにをするの？

:::

ピンクの「**音**」のブロックで、作品に音をつけよう。

- ネコを**鳴かせる**
- いろいろな音を**えらぶ**
- 音を**加工**する・自分の声を**録音**する
- 音の**高さ**を変える

> ⚠ まわりの人のじゃまにならないように、音の大きさに気をつけてね。

:::

📷 ここに画面：「音」のブロックがならんでいるところ

---

# ニャーと鳴かせよう

:::

1. 「**音**」の「**ニャー の音を鳴らす**」を置く
2. ブロックをクリック
3. ネコが「ニャー」と鳴いたら成功！

> 音が聞こえないときは、パソコンの音量がゼロになっていないか、メンターといっしょにたしかめよう。

:::

📷 ここにブロックの画面：「ニャー の音を鳴らす」

---

# 2つの「鳴らす」のちがい

:::

「鳴らす」ブロックは**2つ**あるよ。それぞれ**3つ**つないで、くらべてみよう。

- 「**ニャー の音を鳴らす**」… 鳴らしてすぐ、次のブロックへ。**1回**しか聞こえない
- 「**終わるまで ニャー の音を鳴らす**」… 鳴り終わるまで待つ。**3回**聞こえる

> 音を順番に鳴らしたいときは「**終わるまで**」を使おう。

:::

📷 ここにブロックの画面：「ニャー の音を鳴らす」を3つつないだものと、「終わるまで ニャー の音を鳴らす」を3つつないだものを、左右にならべたもの

---

# 音をふやそう

:::

1. 左上の「**音**」タブをクリック
2. 左下の「**音を選ぶ**」をクリック
3. マウスをのせると、音がためしに鳴る
4. 好きな音をクリック
5. 「**コード**」タブにもどり、「ニャー」の ▼ から、えらんだ音にする

:::

📷 ここに画面：「音」タブの左下の「音を選ぶ」ボタン（印）と、音をえらぶ画面

---

# 音を加工しよう

:::

「**音**」タブでは、音を作りかえられるよ。下のボタンを押してみよう。

- 「**速く**」「**遅く**」… 速さと高さが変わる
- 「**エコー**」… こだまのように
- 「**ロボット**」… ロボットの声に
- 「**逆向き**」… うしろから再生

> もとにもどしたいときは「**元に戻す**」を押してね。

:::

📷 ここに画面：「音」タブの音の波形と、下にならんだ加工のボタン

---

# 自分の声を録音しよう

:::

1. 「**音を選ぶ**」にマウスをのせる
2. 出てきたメニューの「**録音する**」をクリック
3. 左上に「マイクを使用する」と出たら「**許可**」
4. 「**録音する**」を押してしゃべり、「**録音をやめる**」
5. 「**保存**」を押す

> ⚠ まちがえて「ブロック」を押すと録音できないよ。そのときはメンターをよんでね。

:::

📷 ここに画面：「録音」の画面（「録音する」ボタンに印）

---

# 音の高さを変えよう

:::

ブロックで、音の高さや大きさを変えられるよ。

- 「**ピッチ の効果を 10 ずつ変える**」… 音が高くなる
- 「**音の効果をなくす**」… もとの高さにもどす
- 「**音量を 100 %にする**」… 大きさを決める

> 「終わるまで ニャー の音を鳴らす」と「ピッチ の効果を 10 ずつ変える」を交互につなぐと、だんだん高くなるよ。

:::

📷 ここにブロックの画面：「終わるまで ニャー の音を鳴らす」と「ピッチ の効果を 10 ずつ変える」を交互に3回つないだスクリプト

---

# やってみよう

:::

音で、ネコの**おしゃべり**を作ろう。

1. 自分の声で「こんにちは」を録音する
2. 緑の旗で、録音した声を「**終わるまで**」鳴らす
3. 「**ロボット**」で加工した声も鳴らす
4. 最後に、だんだん高くなる「ニャー」を3回鳴らす
5. 「**音の効果をなくす**」で、もとにもどしておく

:::
